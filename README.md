# 公众号文章美化工具

一个纯前端、无需后端的微信公众号文章排版小工具。可以本地运行，也可以部署到 Vercel。

## 功能

- 文章标题和正文编辑
- 实时手机样式预览
- 三套主题：科技蓝、极简黑、暖橙资讯
- 简单 Markdown：`#` / `##` / `###` 标题、`**粗体**`、引用 `>`、无序列表 `-`、分隔线 `---`
- 复制带内联样式的富文本（浏览器支持时）
- 复制 HTML 源码
- 导出独立 HTML 文件
- 不需要后端、数据库或 API Key；文章内容只在浏览器本地处理

## 本地运行

本项目是静态网页，不需要安装依赖：

1. 下载并解压项目。
2. 直接打开 `index.html` 即可预览主要功能。
3. 推荐通过本地 HTTP 服务测试剪贴板功能。Windows 下可直接双击运行根目录的 `start.bat`，脚本会自动检测 Python 或 Node.js 并启动本地服务（默认端口 5500）。
4. 也可以手动启动，例如安装 Node.js 后，在项目目录执行：

```bash
npx serve .
```

然后打开终端提示的本地地址。富文本剪贴板通常需要 HTTPS 或 localhost 环境。

## 部署到 Vercel

### 方式一：GitHub 导入（推荐）

1. 将本项目所有文件提交到 GitHub 仓库。
2. 登录 Vercel，选择 **Add New → Project**，导入该仓库。
3. Framework Preset 选择 **Other**。
4. 不需要 Build Command；Output Directory 使用 `.`（项目根目录）。
5. 点击 Deploy。

如果 Vercel 自动识别为静态站点，也可以直接按自动配置部署。

### 方式二：Vercel CLI

安装 Node.js 后执行：

```bash
npm install -g vercel
cd wechat-article-beautifier
vercel
```

预览确认后正式发布：

```bash
vercel --prod
```

## 使用流程

1. 在左侧输入标题和正文。
2. 正文可使用简单 Markdown 标题和重点标记。
3. 选择主题，在右侧查看效果。
4. 点击「复制排版内容」，打开微信公众号图文编辑器并粘贴。
5. 检查排版效果后发布。建议先发预览或草稿测试。

## 兼容性说明

- 微信公众号后台可能会过滤部分 HTML 或 CSS，不同浏览器复制效果也可能不同。
- 本工具使用内联样式生成导出内容，以提高复制后样式保留概率，但无法保证微信后台对所有样式都完全保留。
- 图片上传、公众号账号登录、直接发布文章不在本项目范围内。
- 参考文章链接未能可靠读取，当前模板为科技资讯风格的初始版本；可根据参考文章截图继续调整。
- 页面使用 Google Fonts 作为可选字体增强；字体无法加载时会回退到系统字体。核心功能不依赖该字体服务。
