# 公众号文章美化工具

一个纯前端、无需后端的微信公众号文章排版小工具。参考 [gzh-design-skill](https://github.com/isjiamu/gzh-design-skill) 的主题设计语言重新实现，内置六套杂志级主题，可本地运行，也可部署到 Vercel。

> 项目地址：[github.com/ilei131/wechat-article-styler](https://github.com/ilei131/wechat-article-styler)

## 六套主题

| 主题 | 气质 | 适合内容 |
| --- | --- | --- |
| 摸鱼绿 | 绿色杂志风，卡片丰富 | 教程、测评、工具清单 |
| 红白色系 | 经典编辑风，编号章节 + 引言卡 | 深度分析、观点、评论 |
| 石墨极简 | 灰阶、水印编号、大留白 | 设计、科技评论、专业观点 |
| 留白禅意 | 衬线书卷气，呼吸感强 | 随笔、禅意、深度长文 |
| 摸鱼票据 | 票据 / 门票视觉隐喻 | 测评、工具对比、创意内容 |
| 橄榄手记 | 内刊编辑部质感，分节多样 | 复盘、深度评测、案例手记 |

每套主题都包含：封面卡、导读目录（票据 / 手记除外）、编号章节、关键词下划线、引用 / 提示块、列表、代码块、表格、图片说明和文末互动区。

## 功能

- 标题、副标题、作者与正文编辑，主题封面自动生成
- 六套主题实时切换，手机宽度预览
- 自动提取章节生成导读目录；标题区域、导读目录、文末互动均可独立开关
- 自动识别 `##` 章节并按顺序编号；检测「总结 / 结语 / 写在最后」使用结语编号
- 正文关键词标记：加粗、高亮、下划线、行内代码、删除线
- Markdown：`#` / `##` / `###` / `####` 标题、引用、`> [!TIP]` 提示、有序 / 无序列表、代码块、表格（含对齐）、图片、分隔线、链接
- 复制带内联样式的富文本；复制 HTML 源码；导出独立 HTML 文件
- 自动保存到浏览器本地（localStorage），刷新不丢内容
- 不需要后端、数据库或 API Key；文章内容只在浏览器本地处理

## Markdown 与标记语法

| 写法 | 效果 |
| --- | --- |
| `# 标题` | 作为文章标题（标题栏为空时） |
| `## 章节` | 主题编号章节 |
| `### 小节` | 主题小节标题 |
| `**加粗**` | 主题强调色加粗 |
| `==高亮==` | 纯色浅底高亮 |
| `++下划线++` | 关键词下划线 |
| `~~删除线~~` | 灰色删除线 |
| `` `代码` `` | 行内代码标签 |
| `> 引用` | 引用 / 金句卡片（开头第一段引用会变成大引言卡） |
| `> [!TIP] 提示` | 提示块（也支持 `[!WARNING]`） |
| `- 项目` | 无序列表 |
| `1. 项目` | 有序列表 |
| ``` 围栏代码块 ``` | 深色代码块 |
| `![说明](图片地址)` | 图片 + 可选说明 |
| 表格 | 主题样式表格 |
| `---` | 分隔线 |
| `[文字](链接)` | 主题色文字标记（公众号会过滤外链，故不生成 `<a>`） |

标题输入框里同样支持 `==关键词==`，用于给封面主标题加主题色强调。

## 本地运行

本项目是静态网页，不需要安装依赖：

1. 下载并解压项目。
2. 推荐通过本地 HTTP 服务运行（富文本剪贴板通常需要 HTTPS 或 localhost）：

```bash
./start.sh
# 或
python3 -m http.server 5500
# 或
npx serve .
```

3. 打开 `http://localhost:5500`。

Windows 下可直接双击运行根目录的 `start.bat`，脚本会自动检测 Python 或 Node.js 并启动本地服务（默认端口 5500）。

直接打开 `index.html` 也能预览主要功能，但剪贴板能力可能受限。

## 部署到 Vercel

### 方式一：GitHub 导入（推荐）

1. 将本项目所有文件提交到 GitHub 仓库。
2. 登录 Vercel，选择 **Add New → Project**，导入该仓库。
3. Framework Preset 选择 **Other**。
4. 不需要 Build Command；Output Directory 使用 `.`（项目根目录）。
5. 点击 Deploy。

### 方式二：Vercel CLI

```bash
npm install -g vercel
cd wechat-article-styler
vercel
```

预览确认后正式发布：

```bash
vercel --prod
```

## 使用流程

1. 填写文章标题、副标题和作者。
2. 在左侧粘贴正文，用简单 Markdown 组织结构。
3. 在右侧切换主题，查看手机预览；按需开关标题、导读目录和文末互动。
4. 点击「复制排版内容」，打开微信公众号图文编辑器并粘贴。
5. 检查图片、间距与字体后，发预览或草稿确认再发布。

## 微信兼容性说明

- 所有导出内容均为内联样式，文字节点使用 `<span leaf="">` 包裹，不使用 `<style>`、`<script>`、`<div>`、class/id、`position:fixed/absolute`、`float`、`@media`、`display:grid`、CSS 变量和外部字体。
- 不含渐变背景，降低公众号暗色模式检测导致弹窗的风险。
- 图片统一 `max-width:100%;height:auto`，不会被强制拉伸。
- 文章最外层使用 `padding:0`，不再叠加左右和底部内边距；粘贴到公众号后看到的少量页边距来自微信原生排版。
- 预览区会用界面 CSS 补一层约 18px 的阅读留白来模拟微信文章页，这层样式只存在于工具界面，不参与复制或导出。
- 微信公众号后台仍可能过滤部分 HTML / CSS，不同浏览器复制效果也可能不同，建议先发预览确认。
- 图片上传、公众号账号登录、直接发布文章不在本项目范围内。

## 文件结构

```
index.html     页面结构
style.css      工具界面样式（不参与导出）
themes.js      六套主题的组件与内联样式
renderer.js    Markdown 解析与文章装配
app.js         界面交互、复制与导出
start.sh       本地启动脚本（macOS / Linux）
start.bat      本地启动脚本（Windows）
```
